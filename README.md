# Veloura

A landing page for **Veloura**, a luxury skincare brand. Built with React and Vite.

## Features

- Responsive hero section with a call to action
- Product showcase with gallery images
- Promotional banners
- Newsletter signup and social links
- Google Fonts (Poppins) typography

## Tech Stack

- [React 19](https://react.dev/)
- [Vite 6](https://vitejs.dev/)

## Getting Started

Requires Node.js 18+.

```bash
npm install
npm run dev
```

The app runs at `http://localhost:5173`.

## Scripts

| Command           | Description                  |
| ----------------- | ---------------------------- |
| `npm run dev`     | Start the dev server         |
| `npm run build`   | Build for production         |
| `npm run preview` | Preview the production build |
